Escape from evil robots (roguebots) that have infested your ship as you run, jump, and invert gravity through a series of platforming/puzzle challenges!

## Installation
### Mac
Mac users (Apple Silicon and Intel chips) can download and run the executable in the ``Executables/`` directory
### Other
Clone the repository and open it via [Unity Hub](https://unity.com/download)
